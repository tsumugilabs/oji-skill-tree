# おじさんスキルツリー 🌳

日常の趣味を記録して、こだわりを進化させるスマートフォン向けジョークアプリ。年齢・性別不問。購入や運動の強度を競うアプリではありません。

## 遊び方
- 分野の「＋ 記録」または「今日のアクションを記録」で実際の行動を記録。
- 1回につき20 XP、100 XPごとに総合レベルが1上がります。
- 各分野の累計1・5・15・30回で4段階のスキルが順番に解放。10分野40スキル。
- 複数分野を進めると4種類の突然変異称号が解放。
- スキルをタップすると解放条件とジョークを表示。
- 活動ログで取り消し、JSONバックアップの保存・復元が可能。

## 開発
外部ライブラリ・外部フォント・ビルド不要のHTML/CSS/JavaScriptです。

```sh
npm start
# http://localhost:8080
npm test
```
Python 3（ローカルサーバー）とNode.js 22以上（テスト）が必要です。file://で開かずHTTPサーバーで配信してください。

## 編集する場所
- `data.js`: 分野、アクション、スキル名、ジョーク、必要回数、突然変異条件
- `model.js`: 経験値、レベル計算、バックアップ検証
- `style.css`: スマホ・PC共通の表示
- `app.js`: 記録、端末内保存、画面表示

## 保存と注意点
データは同一オリジンのlocalStorageに保存されます。アカウント・サーバー保存・端末間同期はありません。ブラウザのデータ削除やURL変更前は活動ログからバックアップしてください。読み込みは既存データを置き換えます。破損データ検知時は上書きを停止します。同時に複数タブで記録すると最後の保存が優先されるため、一つのタブでご利用ください。

## 公開
静的ファイルとして配信できます。GitHub Pagesを使う場合は、リポジトリのSettings → Pagesから、利用可能なプラン・公開設定を確認したうえでmainブランチのルートを選択してください。この初回PRでは公開設定・リポジトリの可視性は変更しません。

参考画像の進化・分岐のアイデアから構成し、画像そのものは同梱していません。初版は各分野内で一本道、分野を横断する突然変異という構成です。

## 放射状スキルマップ
中心の初期状態から10分野へ枝分かれし、外側に向かって各4段階のスキルを配置します。解放経路は分野色、次の経路は点線、未解放は薄い線です。スキルを選ぶと詳細と行動記録ボタンを表示します。

スワイプ・ドラッグ・マップ上の矢印キーで移動、＋−で拡大縮小できます。「全体表示」「中心へ」、分野選択で目的の枝へ移動できます。既存の保存キーと進行条件は変更していません。描画・座標・移動操作は tree.js にあります。
